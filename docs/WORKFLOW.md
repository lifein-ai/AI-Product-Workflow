# Workflow

1. Create or restore a local project.
2. Clarify the requirement in Discovery, then explicitly confirm it.
3. Start Product Solution, refine the proposal, then explicitly confirm it.
4. Generate, review, edit, and confirm the PRD.
5. Generate, review, edit, and confirm the Interaction Specification.
6. Assemble, review, and copy the Codex Figma Prompt.

Confirmed Discovery or Solution can be reopened. Reopening invalidates downstream confirmed state and marks dependent artifacts stale. Current artifacts cannot be regenerated in place; clear them explicitly before creating a replacement.

Decision Memory scanning is manual. Normal Stage Turns remain responsible for explicit decisions.
