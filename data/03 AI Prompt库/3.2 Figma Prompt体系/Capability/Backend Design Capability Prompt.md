# Backend Design Capability Prompt

## Capability定位

负责定义后台系统的通用页面结构、信息组织方式、数据展示方式、配置流程和管理交互模式。

解决：“后台产品通常如何设计和组织。”

不解决：“某个具体业务后台如何实现、业务规则如何定义。”

## 核心能力

- 页面结构能力：支持后台系统常见结构，包括导航、顶部区域、内容区域、列表页、详情页、配置页。 

- 信息组织能力：根据后台使用场景组织数据、配置项、状态和操作入口。 

- 数据展示能力：支持数据概览、趋势展示、列表数据、明细查看等常见展示方式。 

- 查询筛选能力：支持搜索、条件筛选、时间筛选、状态筛选、分页等列表管理模式。 

- 配置管理能力：支持配置列表、新建/编辑、详情查看、操作确认等通用配置流程。 

- 状态模型：支持业务状态、列表状态、操作状态等后台常见状态展示。 

- 权限表达能力：支持按钮权限、操作限制、高风险操作反馈等基础权限表达。 

- 通用交互模式：支持查询、编辑、查看、确认、删除、状态切换等后台操作流程。 

## 通用设计模型

- 全局布局：左侧导航 → 顶部区域 → 内容区域。 

- 数据展示页：数据概览 → 趋势/分析 → 数据列表 → 明细查看。 

- 配置管理页：筛选区域 → 列表区域 → 操作入口 → 编辑/详情。 

- 详情页：基础信息 → 状态信息 → 数据明细 → 操作记录。 

- 配置流程：进入列表 → 创建/编辑 → 确认提交 → 状态反馈。 

- 高风险操作：操作入口 → 确认 → 完成状态。
