# Activity Design Capability

## Capability定位

负责定义移动端运营活动类产品的通用页面结构、信息组织方式、用户参与流程和状态模型。

解决：“运营活动类产品通常如何设计和组织。”

不解决：“某一次活动具体怎么玩、奖励如何配置、业务规则如何定义。”

## 核心能力

- 页面结构能力：支持活动入口、核心信息、参与进度、排名/任务、奖励、规则等模块组织。

- 信息组织能力：围绕用户参与路径展示活动价值、参与方式、当前状态和结果反馈。

- 用户流程能力：支持进入活动、查看信息、参与活动、查看进度、查看奖励、领取奖励等通用流程。

- 状态模型：支持活动生命周期状态（未开始、进行中、已结束）和用户状态（未参与、参与中、可领取、已领取）。

- 通用交互模式：支持活动浏览、排名查看、任务查看、奖励领取、状态反馈等交互。

## 通用设计模型

- 页面结构：活动入口 → 活动信息 → 进度/排名/任务 → 奖励 → 规则。

- 活动状态：未开始 → 进行中 → 已结束。

- 用户状态：未参与 → 参与中 → 达成条件 → 可领取 → 已领取。

- 模块组合：活动信息、数据进度、排名、任务、奖励、规则。
