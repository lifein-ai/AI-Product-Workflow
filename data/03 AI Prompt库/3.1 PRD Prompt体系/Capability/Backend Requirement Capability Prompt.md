# Backend Requirement Capability

## Capability Position

用于分析和整理后台页面、配置流程和数据展示类需求，将后台需求转换为结构化PRD需求信息。

## Analysis Framework

### 页面类型

根据需求识别后台页面类型：

- 数据查看页；

- 配置管理页；

- 操作执行页；

- 审核管理页。

同一页面可包含多个类型。

### 页面目标

分析：

- 页面核心作用；

- 页面使用目的。

### 功能模块

按模块分析：

- 模块名称；

- 展示内容；

- 用户操作；

- 操作后的页面或数据变化。

### 数据展示

涉及数据展示时分析：

- 字段名称；

- 指标定义；

- 数据来源；

- 更新频率。

### 配置能力

涉及配置功能时分析：

- 可配置内容；

- 可修改字段；

- 默认值；

- 生效时间。

### 操作能力

涉及后台操作时分析：

- 操作入口；

- 操作流程；

- 操作结果；

- 异常反馈。

### 权限能力

涉及权限管理时分析：

- 使用角色；

- 查看范围；

- 操作范围。
