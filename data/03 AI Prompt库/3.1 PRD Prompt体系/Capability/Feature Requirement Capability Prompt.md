# Feature Requirement Capability

## Capability Position

用于分析和整理单个功能新增、优化、调整类需求，将功能需求转换为研发可执行需求描述。

## Analysis Framework

功能需求分析需覆盖：

### 功能目标

说明：

- 功能解决的问题；

- 功能建设目的。

### 使用场景

说明：

- 用户角色；

- 使用时机；

- 用户目的。

### 页面需求

说明：

- 页面位置；

- 页面新增内容；

- 页面修改内容；

- 页面删除内容。

### 功能流程

说明：

- 用户操作流程；

- 系统处理逻辑；

- 页面反馈。

### 数据要求

说明：

- 相关字段；

- 数据展示方式；

- 数据来源；

- 更新规则。

### 状态规则

涉及状态时说明：

- 状态定义；

- 状态条件；

- 状态变化；

- 可执行操作。
