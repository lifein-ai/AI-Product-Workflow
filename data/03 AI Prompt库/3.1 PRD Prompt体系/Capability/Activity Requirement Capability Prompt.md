# Activity Requirement Capability

## Capability Position

用于分析和整理完整活动类需求，将活动需求转换为结构化PRD需求信息。

## Analysis Framework

### 活动目标

分析：

- 活动目的；

- 用户参与目标；

- 业务目标。

### 活动流程

分析：

- 用户进入路径；

- 用户参与流程；

- 用户结果获取流程；

- 奖励领取流程。

### 页面需求

分析：

- 页面目标；

- 页面入口；

- 页面展示内容；

- 用户操作；

- 页面状态变化。

页面内容按照模块维度描述：

- 模块名称；

- 展示内容；

- 用户操作；

- 页面变化；

- 状态说明。

### 活动规则信息

识别活动相关规则信息：

- 活动周期；

- 计算方式；

- 排名规则；

- 奖励规则；

- 状态变化。

将规则作为业务信息整理，不自行补充未确认规则。

### 常见活动元素

排行榜类活动关注：

- 排名展示；

- 用户当前排名；

- 上榜状态；

- 未上榜状态。

奖励类活动关注：

- 奖励展示；

- 奖励领取状态；

- 领取入口；

- 领取结果。

### 弹窗与触达

涉及弹窗时分析：

- 触发条件；

- 展示内容；

- 操作按钮；

- 跳转结果。
