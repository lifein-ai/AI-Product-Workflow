# Development Rules

- Use pnpm.
- Reuse existing architecture.
- Do not perform unrelated refactors.
- API keys must stay server-side.
- ModelFlare is accessed through the shared AI client.
- Before modifying code, inspect only files directly related to the task.
- Expand investigation only when dependencies or architecture are unclear.
